# SourceTests
## Badge
Плагин на **TypeScript** для генерации тестовых числовых массивов в текстовый файл (`.txt`). Используется в лабораторных работах для анализа эффективности алгоритмов. Плагин имеет несколько режимов генераций.

## Возможности и режимы
Генерация запускается через **графический интерфейс** и поддерживает 3 режима:
* **Random** — массив рандомных чисел из заданного пользователем диапазона.
* **Sorted** — массив из чисел отсортированных по возрастанию.
* **Same** — массив из одинаковых чисел.

---

## Запуск и использование

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск интерфейса
```bash
npm run test
```

### 3. Порядок действий в UI:
1. Введите **размер** массива.
2. Введите минимальное значение вашего диапазона.
3. Введите максимальное значение вашего диапазона.
4. Выберите один из **трех режимов** генерации.

---

## Сравнение результатов (Пример input.txt)

| Режим | Формат записи в файле | Пример данных |
| :--- | :--- | :--- |
| **Random** | Через пробел | `54 12 89 3 41` |
| **Sorted** | Через пробел | `3 12 41 54 89` |
| **Identical**| Через пробел | `7 7 7 7 7` |

> ⚠️ **Важно:** При повторном нажатии кнопки «Сгенерировать» старый файл перезаписывается автоматически.
