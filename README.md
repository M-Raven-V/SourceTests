# SourceTests

## Badge
**SourceTests** — расширение для Visual Studio Code, написанное на TypeScript, предназначенное для генерации тестовых числовых массивов и сохранения их в текстовый файл `.txt`.

Расширение помогает быстро создавать входные данные для лабораторных работ, связанных с изучением и сравнением эффективности алгоритмов сортировки и обработки массивов.

## Возможности и режимы
Генерация запускается через **графический интерфейс** и поддерживает 3 режима:

* **random** — генерация массива случайных целых чисел в заданном диапазоне.
* **sorted** — генерация массива случайных целых чисел с последующей сортировкой по возрастанию.
* **same** — генерация массива, состоящего из одинаковых чисел.

## Требования

Для работы с исходным кодом расширения необходимы:

- [Visual Studio Code](https://code.visualstudio.com/)
- [Node.js](https://nodejs.org/)
- npm — менеджер пакетов, устанавливаемый вместе с Node.js.

## Запуск и использование

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
cd SourceTests
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Компиляция TypeScript

```bash
npm run compile
```

### 4. Запуск расширения в режиме разработки

1. Откройте проект в Visual Studio Code.
2. Нажмите `F5`, чтобы запустить новое окно VS Code с расширением.
3. Откройте интерфейс SourceTests и задайте параметры генерации.
4. Сгенерируйте тестовый массив.

> **Примечание:** Для запуска расширения в режиме разработки используется команда `F5` (Run and Debug).В проекте настроен стандартный сценарий VS Code Extension Development Host.

## Инструкция по использованию

1. Укажите размер массива.
2. Введите минимальное значение диапазона.
3. Введите максимальное значение диапазона.
4. Выберите режим генерации: `random`, `sorted` или `same`.
5. Нажмите кнопку генерации.
6. Используйте полученный файл `.txt` в своей программе для тестирования алгоритмов.

### Пример входных данных

Для массива из пяти элементов возможны следующие результаты:

| Режим | Пример массива |
|---|---|
| `random` | `54 12 89 3 41` |
| `sorted` | `3 12 41 54 89` |
| `same` | `7 7 7 7 7` |

Пример содержимого файла `input.txt`:

```text
54 12 89 3 41
```

Фактический результат зависит от введённых параметров и выбранного режима.

> **Важно:** Расширение перезаписывает файл при повторной генерации, сохраните необходимые данные заранее. Предыдущий результат может быть утрачен.

## Применение

SourceTests можно использовать для подготовки тестовых данных при изучении алгоритмов и структур данных.

В частности, разные режимы позволяют исследовать поведение алгоритмов на различных типах входных последовательностей:

- **Случайный массив** — проверка работы алгоритма на неупорядоченных данных.
- **Отсортированный массив** — исследование поведения алгоритма на уже упорядоченных данных.
- **Массив одинаковых элементов** — проверка обработки повторяющихся значений.
